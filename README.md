# ABC Creations – NFC Digital Business Card

A lightweight, mobile-responsive NFC landing page for ABC Creations.

## Features
- Direct WhatsApp chat link
- Google Maps location
- Official website link
- Instagram profile link
- Dark / Light mode support based on system settings

## Deployment with GitHub Pages
1. Go to your repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` and root (`/`).
3. Click **Save**.
4. Your NFC landing page URL will be live at:
   `https://<your-username>.github.io/<repo-name>/`
